# 1. Objetivo

Explicar que esta guía inicia la etapa de construcción.

Este documento define la transición desde la planificación hacia el desarrollo de NIDO v0.1.

# 2. Estado actual del proyecto

La documentación base está aprobada y sirve como referencia para iniciar la implementación.

# 3. Principios antes de programar

- leer documentación existente.
- no improvisar arquitectura.
- mantener nombres en español.
- priorizar simplicidad.
- construir por etapas.

# 4. Método de trabajo con IA

Definir:

- analizar antes de crear.
- explicar cambios.
- modificar solo lo solicitado.
- informar archivos afectados.
- verificar funcionamiento.

# 5. Primera etapa de programación

Definir:

Crear base PWA funcional.

Incluye:

- estructura HTML.
- estilos iniciales.
- JavaScript base.
- manifest.
- service worker.

# 6. Primera prueba funcional

Definir:

La aplicación debe abrir correctamente y mostrar la pantalla inicial de NIDO.

# 7. Reglas para futuras modificaciones

Incluir:

- no romper funcionalidades existentes.
- actualizar documentación cuando corresponda.
- respetar arquitectura.

# 8. Flujo de desarrollo

Definir:

Documentación.
↓
Diseño.
↓
Implementación.
↓
Pruebas.
↓
Aprobación.

## Resumen de decisión

Comienza oficialmente la construcción de NIDO v0.1.
