# 10 - Modo Docente NIDO

## Propósito

Definir el espacio destinado a docentes para crear, adaptar y acompañar experiencias educativas.

## Funciones del docente

- Crear estudiantes.
  - Permitir dar de alta perfiles de estudiantes y gestionar sus datos básicos.

- Crear grupos.
  - Organizar estudiantes en grupos para gestionar experiencias compartidas.

- Crear aventuras educativas.
  - Definir nuevas aventuras con objetivos, descripción y temas.

- Crear desafíos.
  - Generar actividades que forman parte de las aventuras.

- Cargar imágenes.
  - Añadir recursos visuales para apoyar las preguntas y el contenido.

- Cargar audios.
  - Incluir archivos de audio para narraciones, instrucciones o pistas.

- Configurar niveles.
  - Ajustar la dificultad y el alcance de las aventuras según el grupo o el estudiante.

- Adaptar actividades.
  - Modificar desafíos y rutas de aprendizaje para responder a necesidades específicas.

## Creación de contenido

El docente puede crear contenido sin modificar el motor educativo.

- El motor interpreta estructuras configurables que describen las aventuras y desafíos.
- El docente trabaja sobre datos de contenido, no sobre la lógica del sistema.
- Esto permite que el motor permanezca estable mientras se generan nuevas experiencias.

Ejemplo:

Una aventura de Física:

Título:
"Descubrimos la masa"

Tema:
Magnitudes físicas

Nivel:
Inicial

Desafíos:
- Reconocer instrumentos.
- Relacionar objetos.
- Responder preguntas visuales.

## Seguimiento educativo

El modo docente permite observar y apoyar el proceso de aprendizaje.

- Progreso.
  - Ver el avance de los estudiantes en las aventuras.

- Avances.
  - Identificar los logros alcanzados y las metas superadas.

- Dificultades.
  - Detectar áreas donde el estudiante requiere apoyo.

- Tiempo de interacción.
  - Registrar cuánto tiempo dedica el estudiante a la experiencia.

- Recomendaciones.
  - Ofrecer sugerencias pedagógicas para ajustar el contenido y el ritmo.

## Principios del modo docente

- No reemplazar al docente.
  - El modo docente es una herramienta de apoyo, no un sustituto del educador.

- Ser una herramienta de acompañamiento.
  - Debe facilitar el trabajo del docente con recursos claros y accesibles.

- Permitir personalización.
  - El docente debe poder adaptar las experiencias a las necesidades de sus estudiantes.

- Mantener accesibilidad.
  - El modo docente debe ser usable por docentes con distintos niveles de experiencia y debe garantizar que el contenido sea inclusivo.

## Resumen

Este documento define el modo docente de NIDO como un espacio para crear, adaptar y acompañar experiencias educativas. Describe las funciones del docente, cómo puede crear contenido sin tocar el motor, el seguimiento educativo y los principios clave de esta modalidad. Asimismo, establece que el docente participa en el primer ingreso de NIDO cuando se selecciona el rol docente, y que su flujo principal es: configuración/inicio docente → creación o selección de grupo → gestión del espacio docente.
