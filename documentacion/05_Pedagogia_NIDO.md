# Pedagogía NIDO

## 1. Filosofía educativa

NIDO se concibe como un compañero de aprendizaje que acompaña al estudiante en cada paso, no como una entidad que impone el conocimiento.

- NIDO como compañero de aprendizaje
  - La experiencia se diseña alrededor de la presencia cercana, el apoyo constante y la confianza.
  - El estudiante siente que no está solo, sino acompañado por un guía amigable.

- Aprendizaje basado en acompañamiento
  - El motor educativo propone, sugiere y guía, mientras el estudiante realiza la actividad.
  - Las decisiones pedagógicas buscan acompañar el proceso, no sustituirlo.

- Importancia del ritmo individual
  - Cada estudiante avanza a su propio ritmo y la experiencia se adapta a esa velocidad.
  - Se evita presionar al estudiante con tiempos rígidos; se prioriza la permanencia en un flujo cómodo.

## 2. Rol de la mascota

Pipo es el vínculo emocional y pedagógico que articula la experiencia.

- Presenta desafíos
  - Introduce las actividades con un tono amigable y motivador.
  - Establece el contexto y el objetivo de cada desafío.

- Explica
  - Aporta explicaciones claras y sencillas cuando el estudiante necesita orientación.
  - Usa lenguaje accesible y ejemplos cercanos.

- Anima
  - Refuerza la confianza con mensajes positivos.
  - Mantiene el ánimo del estudiante cuando enfrenta dificultades.

- Celebra
  - Reconoce los avances y logros con refuerzos emocionales.
  - Hace que cada paso positivo se perciba como un motivo de celebración.

- Acompaña errores
  - Acompaña los errores con calma, sin juicio.
  - Los presenta como oportunidades para aprender y mejorar.

## 3. Aprendizaje sin ansiedad

NIDO promueve un entorno seguro y libre de castigos que favorece la curiosidad y la experimentación.

- Errores como parte del aprendizaje
  - Los errores son vistos como señales de aprendizaje, no como fracasos.
  - Cada error ofrece información útil para redirigir el camino.

- Ausencia de castigos
  - No hay sanciones ni penalizaciones por respuestas incorrectas.
  - El sistema refuerza la exploración sin miedo.

- Refuerzo positivo
  - Se destacan los aciertos, los esfuerzos y los avances.
  - El lenguaje y las recompensas se diseñan para motivar.

- Repetición amigable
  - La repetición se plantea como práctica necesaria y no como castigo.
  - Las actividades repetidas se presentan con variaciones y apoyo.

## 4. Aprendizaje visual e interactivo

La pedagogía de NIDO aprovecha elementos visuales y sensoriales para facilitar la comprensión.

- Imágenes
  - Usar imágenes claras y significativas para apoyar conceptos.
  - El contenido visual complementa el texto y reduce la carga cognitiva.

- Sonidos
  - Los sonidos refuerzan la atención, la emoción y la orientación.
  - Se utilizan efectos y narraciones suaves.

- Animaciones
  - Las animaciones explican procesos y muestran cambios de forma comprensible.
  - Deben ser breves, coherentes y fáciles de seguir.

- Ejemplos cotidianos
  - El aprendizaje se conecta con situaciones cercanas al estudiante.
  - Se usan ejemplos simples para hacer tangibles los conceptos.

## 5. Adaptación al estudiante

NIDO se adapta para mantener el desafío apropiado y reconocer los avances individuales.

- Dificultad progresiva
  - Las actividades aumentan su complejidad de forma gradual.
  - El sistema debe construir confianza antes de introducir retos más difíciles.

- Repetición inteligente
  - Se repite lo necesario para consolidar, usando variaciones que eviten la monotonía.
  - La repetición se aplica cuando hay señales de falta de comprensión.

- Reconocimiento de avances
  - Cada logro y cada paso se reconoce para reforzar la motivación.
  - El progreso se muestra de forma clara y accesible.

## 6. Estructura de una actividad

Una actividad de NIDO sigue una secuencia clara y coherente.

- Inicio
  - Presentación del contexto y la motivación.
  - Preparación del estudiante para lo que vendrá.

- Presentación
  - Introducción del contenido con un lenguaje simple.
  - Exposición de los elementos clave del desafío.

- Desafío
  - Planteamiento de la tarea de forma directa y comprensible.
  - Presentación de la interacción que el estudiante debe realizar.

- Respuesta
  - Espacio para que el estudiante seleccione o construya la solución.
  - La interacción debe ser clara y sin ambigüedades.

- Explicación
  - Retroalimentación inmediata que aclara por qué la respuesta es correcta o incorrecta.
  - Apoyo que ayuda a comprender el concepto subyacente.

- Recompensa
  - Refuerzo positivo después de la participación.
  - Incentivos que valoran tanto el esfuerzo como el resultado.

## 7. Evaluación

La evaluación en NIDO no se limita a medir respuestas correctas.

- Progreso
  - Se valora el avance continuo en las aventuras y contenidos.
  - El seguimiento de progreso permite reconocer mejoras.

- Comprensión
  - Se observa si el estudiante interioriza conceptos, no solo si responde correctamente.
  - Las explicaciones y repeticiones ayudan a profundizar la comprensión.

- Confianza
  - Se evalúa si el estudiante se siente cómodo con el proceso.
  - El diseño busca fortalecer la autoestima y la seguridad.

- Participación
  - Se considera la disposición del estudiante a interactuar.
  - La participación activa es un indicador clave de compromiso.

## 8. Inclusión

NIDO se orienta a ser accesible y amigable para distintos perfiles de estudiantes.

- Principios para estudiantes con diferentes necesidades
  - Interfaces simples y directas.
  - Texto claro y apoyos visuales contundentes.
  - Opciones de interacción variadas y adaptables.
  - Ritmo propio y respeto por los tiempos individuales.

- Diseño inclusivo
  - Se evita la sobrecarga sensorial.
  - Las explicaciones se presentan con recursos múltiples.
  - Se considera diversidad en capacidades cognitivas y de atención.

## 9. Futuro educativo

Los principios pedagógicos de NIDO pueden aplicarse de forma consistente a nuevas materias.

- Aplicación a nuevas materias
  - El acompañamiento, el ritmo individual y el refuerzo positivo son válidos para cualquier área.
  - El modelo visual e interactivo sirve para Física, Matemática, Lengua, Ciencias y más.

- Escalabilidad pedagógica
  - Cada materia nueva puede mantener la misma estructura de actividades.
  - Los principios garantizan coherencia entre experiencias educativas.

- Evolución sin perder identidad
  - El núcleo pedagógico de NIDO permanece estable al crecer el catálogo de contenidos.
  - Los nuevos temas se integran bajo el mismo enfoque de cuidado y acompañamiento.

## Resumen

NIDO propone una pedagogía centrada en el acompañamiento, la confianza y el ritmo individual. La mascota Pipo guía al estudiante, presenta desafíos y celebra los avances. El sistema rechaza la ansiedad y los castigos, potenciando refuerzo positivo, repetición amigable, aprendizaje visual e inclusión. Estos principios se pueden aplicar a nuevas materias sin cambiar el marco educativo central.
