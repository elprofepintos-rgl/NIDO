# 1. Objetivo del documento

Este documento define el camino de desarrollo de la primera versión de NIDO.

# 2. Nombre de versión

NIDO v0.1 — "El Primer Nido"

# 3. Objetivo general

Crear una primera experiencia educativa funcional.

# 4. Alcance de la versión 0.1

PWA:

- aplicación instalable.
- funcionamiento básico offline.

Usuarios:

- adulto responsable.
- estudiante.

Perfil estudiante:

- creación de perfil.
- elección de mascota.
- espacio personal Mi NIDO.

Mascota:

- presentación.
- expresiones básicas.
- acompañamiento.

Motor educativo:

- cargar aventura.
- mostrar desafío.
- evaluar respuesta.
- entregar recompensa.

Contenido inicial:

Materia:
Física

Temas:

- masa.
- longitud.
- tiempo.

# 5. Fuera de alcance

Esta versión inicial no incluirá funcionalidades avanzadas como modo docente completo, gestión de grupos compleja, múltiples materias más allá de Física, integraciones externas, o personalización profunda avanzada. Estos elementos quedarán para futuras versiones.

# 6. Orden de desarrollo

Etapa 1:
Base técnica PWA.

Etapa 2:
Interfaz inicial.

Etapa 3:
Sistema de usuarios.

Etapa 4:
Sistema mascota.

Etapa 5:
Motor educativo.

Etapa 6:
Primera aventura Física.

Etapa 7:
Pruebas.

# 7. Criterios de aceptación

NIDO v0.1 estará terminado cuando:

- la aplicación se pueda instalar como PWA.
- funcione de manera básica sin conexión.
- el adulto responsable pueda crear y configurar el perfil del estudiante.
- el estudiante pueda elegir una mascota y acceder a Mi NIDO.
- el motor educativo cargue una aventura, muestre desafíos, evalúe respuestas y entregue recompensas.
- exista contenido inicial de Física con masa, longitud y tiempo.

NIDO se desarrollará progresivamente priorizando calidad, accesibilidad y estabilidad.
