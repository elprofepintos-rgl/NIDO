# 09 - Experiencia Inicial NIDO

## Propósito

Definir cómo una persona ingresa por primera vez a NIDO y qué pasos iniciales se deben seguir para poner en marcha la experiencia educativa.

## Roles principales

1. Adulto Responsable
   - Persona que configura y supervisa el uso de NIDO.
   - Responsable de las primeras decisiones y de la seguridad del entorno.

2. Docente
   - Persona con rol pedagógico que puede crear, adaptar y acompañar el proceso educativo.
   - Puede usar NIDO para apoyar el aprendizaje con contenidos y seguimiento.

3. Estudiante
   - Persona que usa la aplicación para aprender.
   - Interactúa con la mascota y realiza las aventuras educativas.

## Flujo inicial de ingreso

- Primera apertura de NIDO.
  - La aplicación se inicia mostrando una bienvenida clara y amigable.
  - Se presenta la propuesta de NIDO como un espacio seguro y motivador.
  - Si el sistema aún no tiene una configuración establecida, aparece la pregunta: "¿Quién está ingresando?"

- Selección inicial de rol.
  - El usuario elige entre Adulto Responsable y Docente.
  - La opción Adulto Responsable configura y acompaña el espacio del estudiante.
  - La opción Docente accede al inicio docente y a la gestión del contenido educativo.

- Configuración inicial realizada por un adulto responsable.
  - El adulto configura las opciones básicas de uso, como el idioma, el perfil del estudiante y el tiempo de uso.
  - Se define el entorno seguro para el niño o niña.

- Creación del perfil del estudiante.
  - Se crea uno o varios perfiles de estudiante con nombre, avatar y preferencias.
  - El perfil permite personalizar el recorrido educativo.

- Preparación del espacio educativo.
  - El adulto establece el dispositivo y el lugar donde el estudiante utilizará NIDO.
  - Se revisan las opciones de accesibilidad y la configuración de sonido.

- Inicio de la experiencia del estudiante.
  - Una vez configurado, el estudiante accede directamente a su espacio personal.
  - El acceso habitual del estudiante debe ser: NIDO → Mi NIDO → JUGAR.
  - El estudiante no debe atravesar la configuración administrativa para poder aprender.

## Adulto Responsable

- Registro inicial.
  - El adulto accede a la aplicación y configura el primer acceso.
  - Se establece un perfil responsable que protege la configuración.

- Creación de perfiles.
  - Se crean perfiles de estudiantes para cada niño o niña que usará NIDO.
  - Cada perfil guarda progreso, preferencias y datos de avance.

- Configuración de tiempo de uso.
  - Se define cuánto tiempo puede usar el estudiante la aplicación en cada sesión.
  - Esta configuración ayuda a mantener un uso equilibrado.

- Administración básica.
  - El adulto puede revisar el avance general y ajustar parámetros de uso.
  - Puede gestionar permisos y controles básicos.

- Protección de configuraciones.
  - Las opciones clave quedan protegidas para que el estudiante no las cambie inadvertidamente.
  - El adulto mantiene el control sobre el entorno.

- Acompañamiento del estudiante.
  - El adulto está presente en los primeros momentos de uso.
  - Se asegura de que el estudiante entienda la experiencia y se sienta apoyado.

## Estudiante

- Acceso a su espacio personal.
  - El estudiante entra a un perfil propio con su avatar, nombre y preferencias.
  - El espacio está diseñado para ser reconocido fácilmente.

- Interacción con la mascota.
  - La mascota acompaña y guía en cada paso.
  - El estudiante recibe mensajes de ánimo y explicaciones claras.

- Aventuras educativas.
  - El estudiante inicia aventuras que combinan aprendizaje y juego.
  - Las actividades se presentan como retos accesibles.

- Recompensas.
  - El estudiante recibe incentivos como monedas, estrellas o elementos para la mascota.
  - Las recompensas refuerzan el interés y el esfuerzo.

- Progreso.
  - Se registra el avance en cada aventura.
  - El estudiante puede ver cómo avanza y qué ha logrado.

## Principios de experiencia

- Seguridad.
  - El entorno inicial debe ser seguro y protector.

- Acompañamiento.
  - La experiencia se diseña para que el estudiante no esté solo.

- Simplicidad.
  - Los pasos y las pantallas iniciales deben ser fáciles de entender.

- Accesibilidad.
  - La configuración debe permitir adaptaciones para distintas capacidades.

- Evitar ansiedad.
  - La experiencia debe ser tranquila y no generar presión.

- Aprendizaje positivo.
  - Se enfatiza el refuerzo positivo y el reconocimiento de avances.

## Resumen

Este documento describe la experiencia inicial de NIDO, los roles del adulto responsable, docente y estudiante, el flujo de ingreso, las funciones del adulto y la primera interacción del estudiante. También establece los principios de seguridad, acompañamiento, simplicidad, accesibilidad, evitar ansiedad y aprendizaje positivo.
